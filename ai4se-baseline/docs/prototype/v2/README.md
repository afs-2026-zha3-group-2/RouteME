# RouteME 原型图 v2（六屏设计板）

按 2026-11-17 提供的六屏设计参考图（浅蓝灰画布 + 3×2 编号栅格 + 左栏导航）重做的一版原型。参考图未随仓库保留，视觉口径已固化在 `assets/` 的样式令牌里。

直接用浏览器打开 [index.html](index.html) 即可（纯静态、零依赖、可 file:// 打开）。点击任意一屏进入放大层，Esc 退出，← → 切屏。

## 六屏

| # | 屏 | 覆盖的业务闭环 | 放大层内可交互 |
|---|---|---|---|
| 1 | 旅行灵感（浏览） | 灵感入口、分类、推荐行程、发布引导 | 收藏喜欢、分类点击态 |
| 2 | 旅行地图（地图探索） | 地图找行程、筛选、附近行程 | 筛选 chips、点位、图层面板 |
| 3 | 发布行程（创建行程） | 基本信息 → 路线规划 → 同行设置 → 发布前提醒 | 标签选择、途经点 |
| 4 | AI 规划（智能推荐） | 对话式规划、行程卡、发布成招募 | 规划/行程 tabs、快捷追问、发送消息 |
| 5 | 我的旅行（行程管理） | 我发布的 / 我参加的 / 草稿 / 收藏 | 状态 tabs、编辑入口 |
| 6 | 同行消息（社交沟通） | 会话列表、行程卡消息、安全提示 | 会话切换、筛选、发送消息（含模拟回复） |

放大层的左侧导航可以在六屏之间直接跳转，用于演示主流程。

## 设计口径

- **画布**：每屏固定 1120 × 1142（对应参考图近正方形取景），设计板按屏框宽度等比 `scale()`，因此缩略与放大是同一套 DOM，不会失真。
- **令牌**：主色 `--teal #1aa79b`，正文 `--ink #16223a`，辅助 `--ink-3 #8b95a9`，贯穿六屏；状态色沿用行程四态（招募中 / 已成行 / 已满员 / 草稿）。
- **配图**：原型不联网，卡面与地图用分层渐变 + 几何形状生成占位取景（`assets/app.js` 的 `art()`）；接真实图片时把 `.art` 的 `<svg>` 换成 `<img>` 即可。
- **字体**：系统字体栈（Inter / PingFang SC / Microsoft YaHei），不加载外部字体。
- **响应式**：设计板 3 列 → 2 列（≤1240px）→ 1 列（≤780px）；屏内应用本身不重排，避免缩略图与放大层不一致。

## 文件

| 文件 | 作用 |
|---|---|
| [index.html](index.html) | 设计板 + 放大层骨架 |
| `assets/board.css` | 画布、编号标题、屏框、放大层 |
| `assets/app.css` | 屏内应用样式（侧栏 / 六屏组件） |
| `assets/data.js` | 演示数据（用户、行程、会话、AI 往返） |
| `assets/app.js` | 图标、占位配图、六屏渲染 |
| `assets/board.js` | 栅格装配、等比缩放、放大层与轻交互 |

## 边界

- 本版是**视觉与流程提案**，不替代活规格（`openspec/specs/`）与接口契约（`openapi.yaml`），也不替代生产前端（`RouteME/frontend/`）。
- 数据全部是演示口径，不连后端；表单不做校验，仅表达字段与信息层级。
- 上一版交互原型完整保留在 [../v1/](../v1/)（含用户故事与发现报告），两版互不覆盖。
