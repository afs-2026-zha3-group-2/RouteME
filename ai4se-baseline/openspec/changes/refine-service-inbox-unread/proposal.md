# 变更提案：refine-service-inbox-unread

- **需求来源：** 用户验收反馈（2026-11-18）「如果有收到新消息需要置顶展示，采用一个气泡提示」「把提示语『队列与消息每 3 秒自动刷新，接入前也可以先读用户消息。』删除」｜ **归属：** REQ-018 客服能力（不新增需求编号）
- **能力：** `customer-service`（ADDED Requirements：新消息置顶与气泡）
- **规模：** XS（仅前端队列状态与样式）
- **规则：** `@rule:spec-first`、`@rule:web-coding-style`、`@rule:tdd-cycle`
- **本回合状态：** P4 已实现并通过门禁（前端 `typecheck` + 446 tests + `build`；E2E `admin` 11/11、`customer-service` 2/2）。

## 问题

客服队列虽然 3 秒轮询，但新消息到达后：
- 会话仍按服务端顺序排列（等待接入按创建时间升序），新消息不一定在视野内；
- 没有任何未读提示，管理员容易漏看；
- 队列页顶部常驻一句「队列与消息每 3 秒自动刷新，接入前也可以先读用户消息。」，属于噪声。

## 范围

**In scope**

- 队列轮询发现「会话消息数增长」或「新出现的会话已带消息」时，将该会话置顶，并在队列项右上角显示新消息条数气泡（危险色）。
- 点击会话（宽屏选中 / 窄屏跳详情）即清除该会话气泡；选中会话期间新到消息不累计气泡。
- 删除队列页的刷新提示文案与对应样式。

**Out of scope**

- 服务端未读持久化、跨设备已读同步。
- 浏览器通知 / 声音提醒、未读总数徽标（页签徽标仍只统计 `WAITING`）。
- 后端接口与数据模型（`/api/admin/service/**` 不变）。

## 影响面

- 前端：`admin/service/AdminServicePage.tsx`（消息条数基线、未读状态、置顶排序、气泡）、`i18n/adminMessages.ts`、`styles.css`。
- 测试：`e2e/tests/admin.spec.ts` `[I3]`（置顶 + 气泡 + 点击清除 + 提示语已移除）。
- 后端 / 契约 / 迁移：无。
