# user-auth 增量规格（add-user-logout）

## ADDED Requirements

### Requirement: 退出当前身份

系统 SHALL 允许已进入系统的用户从顶栏身份菜单退出当前身份并返回身份门；退出入口 MUST 对注册账号与演示身份同样可见。注册账号退出 MUST 结束其服务端会话，演示身份退出 MUST 只清除本地身份且 MUST NOT 要求密码或发起认证请求。

#### Scenario: 注册账号退出登录
- **Given** 用户以注册账号登录并停留在任意页面
- **When** 用户在顶栏身份菜单点击「退出登录」
- **Then** 系统结束该账号的当前会话并清除本地会话与当前身份
- **And** 界面返回身份门，不保留上一账号的顶栏身份
- **And** 已结束的会话凭据再次用于读取当前用户返回 401

#### Scenario: 演示身份退出当前身份
- **Given** 用户以某个预设演示身份进入系统
- **When** 用户在顶栏身份菜单点击「退出登录」
- **Then** 系统清除当前演示身份并返回身份门
- **And** 不发起认证请求，也不要求密码
- **And** 身份门仍展示 3 个预设演示账户与既有登录 / 注册入口

#### Scenario: 退出入口对所有身份可见
- **Given** 用户已进入系统，且当前身份是注册账号或演示身份之一
- **When** 用户展开顶栏身份菜单
- **Then** 菜单展示「退出登录」入口
- **And** 该入口不因身份类型被隐藏

#### Scenario: 结束会话失败仍完成本地退出
- **Given** 注册账号持有有效会话
- **When** 用户退出登录且结束会话的请求失败
- **Then** 系统仍清除本地会话与当前身份并返回身份门
- **And** 系统可以提示会话可能仍有效，但不阻止退出

#### Scenario: 退出后刷新不恢复身份
- **Given** 用户刚退出当前身份并停留在身份门
- **When** 用户刷新页面
- **Then** 系统不恢复上一身份或上一会话
- **And** 页面停留在身份门，可重新选择演示身份或登录

#### Scenario: 身份门不展示退出入口
- **Given** 用户尚未进入系统或刚退出并停留在身份门
- **When** 用户查看页面
- **Then** 系统不展示「退出登录」入口
- **And** 用户重复触发退出时保持身份门状态且不报错
