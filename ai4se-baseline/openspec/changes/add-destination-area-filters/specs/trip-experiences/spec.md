# trip-experiences 增量规格

## MODIFIED Requirements

### Requirement: 灵感首页的旅行体验视图

系统 SHALL 在灵感首页提供「招募中的行程」与「旅行体验」两个视图切换，并 MUST 默认进入「招募中的行程」；「旅行体验」MUST 按页展示已发布体验所属的行程标题、目的地、作者、强度、感受摘要与来源行程「已结束」标识，并按发布时间倒序排列。系统 SHALL 支持按目的地、日期区间与兴趣标签筛选体验：目的地 MUST 通过省市级联选到市并按 6 位代码等值匹配；日期区间 MUST 按"体验关联行程的日期区间与所选区间有交集"判定；兴趣标签 MAY 多选，命中任一即保留。体验卡与详情的目的地名称 MUST 使用行政区划字典标准名（普通城市市名、直辖市省级名、港澳台"省级简称 · 二级名"）；体验卡 MUST NOT 显示日期。系统 MUST NOT 提供关键词搜索。来源行程「已结束」MUST 以文字或图形表达，不得仅以颜色表达；没有结果时 MUST 给出空态提示与「去发布行程」引导并保留已选条件；数据未返回时 MUST 展示骨架或加载态，且不得残留上一视图的卡片。

#### Scenario: 切换到旅行体验视图
- **Given** 首页已有已发布体验
- **When** 用户从默认的「招募中的行程」切换到「旅行体验」
- **Then** 列表展示体验卡而不是行程卡
- **And** 展示体验数量
- **And** 当前视图具有可访问的选中标识

#### Scenario: 体验卡标识来源行程已结束
- **Given** 一条体验来自已结束的行程
- **When** 用户查看「旅行体验」视图的体验卡
- **Then** 卡片展示来源行程标题、目的地与「已结束」标识
- **And** 该标识不只依赖颜色表达

#### Scenario: 体验筛选与倒序
- **Given** 存在多条不同目的地/标签/日期的体验
- **When** 用户按目的地、日期或兴趣筛选
- **Then** 只展示命中的体验
- **And** 结果按发布时间从新到旧排列

#### Scenario: 按目的地筛选体验
- **Given** 存在不同目的地的体验
- **When** 用户选择"广东省 / 珠海市"
- **Then** 只展示关联行程 `destination_code = 440400` 的体验
- **And** 摘要显示"已应用筛选：广东省 / 珠海市"

#### Scenario: 按日期区间筛选体验
- **Given** 体验关联的行程具有起止日期
- **When** 用户设置出发不早于与/或出发不晚于
- **Then** 只展示关联行程日期区间与所选区间有交集的体验
- **And** 只设置一边时按单边条件筛选

#### Scenario: 体验筛选组合
- **Given** 用户同时设置了目的地、日期区间与兴趣标签
- **When** 系统筛选体验
- **Then** 只保留同时满足全部条件的体验

#### Scenario: 体验分页与筛选并用
- **Given** 用户已设置目的地、日期或兴趣条件
- **When** 用户翻页
- **Then** `total` 反映筛选后的命中数
- **And** 每页条目仍是筛选后的子集

#### Scenario: 筛选变化重置体验分页
- **Given** 用户停在体验视图的第 2 页
- **When** 用户修改任一筛选条件
- **Then** 体验列表从第 1 页重新查询

#### Scenario: 体验空态
- **Given** 当前筛选条件下没有体验
- **When** 用户查看「旅行体验」视图
- **Then** 系统展示空态提示与「去发布行程」引导
- **And** 保留已选条件，不自动清空
- **And** 提示可通过完成旅行并分享来产生内容
- **And** 不展示分页控件

#### Scenario: 体验视图加载态
- **Given** 体验数据尚未返回
- **When** 用户查看「旅行体验」视图
- **Then** 系统展示骨架或加载态
- **And** 不展示上一视图的行程卡

#### Scenario: 体验卡地名口径
- **Given** 体验关联的行程位于不同行政区
- **When** 用户查看体验卡
- **Then** 普通城市显示市名（如"珠海市"）
- **And** 直辖市显示省级名（如"北京市"）
- **And** 港澳台显示"省级简称 · 二级名"（如"香港 · 香港岛"）

#### Scenario: 体验卡不显示日期
- **Given** 一条体验卡
- **When** 用户查看卡片
- **Then** 卡片不显示关联行程日期或体验发布时间
- **And** 日期筛选仍按"按日期区间筛选体验"生效

#### Scenario: 体验视图无关键词搜索
- **Given** 用户位于「旅行体验」视图
- **When** 页面渲染
- **Then** 不出现关键词搜索框
- **And** 请求不携带关键词参数
