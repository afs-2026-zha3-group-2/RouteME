## 规格解释裁决

1. **「旅行日期」取首日。** 多日行程展示旅行开始日期的天气，并在卡片上标注日期；逐天预报不在本 change。
2. **「暂无该日期天气预报」是业务状态，不是错误。** 用 200 + `available:false` 表达，前端单独提示，不进入失败重试路径。
3. **天气失败不阻断业务。** 发布提交、详情浏览与同行操作均不依赖天气结果。
4. **UV 不可用不等于 0。** 上游缺省时响应为 `null`，页面不展示 UV 行，也不生成紫外线提醒。
5. **提醒阈值固定。** 阈值是产品口径常量，不在运行时由前端传入或由 AI 决定。
