完善 / 编辑页

同一个页面承担「首次完善」与「再次编辑」：未完善时显示「跳过」，已完善时显示「取消」。

  • 必填 6 项：昵称、生日、性别、所在城市、兴趣（3–5）、旅行方式；其余全部选填。
  • 生日用原生 date 控件；年龄与星座由服务端派生，表单不展示计算结果。
  • 学校与专业是两个输入框，展示时才拼「学校 · 专业」，用户不输入 ·。
  • 兴趣计数常驻；选满 5 个后新增按钮禁用；取消自定义标签仍保留为未选卡片。
  • 勾选顶部「模拟缺项提交」查看字段级错误 + 汇总提示（E2 / E11）。

  • 回退顺序：学校 · 专业 → 职业 → 城市 → 不显示。

  • 体验卡作者、行程详情发布者使用同样的入口与摘要规则。
  • 摘要只读，随资料更新立即生效；不新增行程业务规则。

状态说明

顶部工具栏可切换页面、身份、资料完整度与主题；预览数据仅用于评审，不代表真实账号。

评审关注点

  • 必填 6 项是否足够，选填是否过多。
  • 「学校 · 专业」拼接是否需要分隔符以外的格式。
  • 未完善资料的降级展示是否足够友好。
  • 发布者摘要回退顺序是否可接受。
