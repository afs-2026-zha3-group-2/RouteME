# design-system 增量规格（add-user-profile）

## MODIFIED Requirements

### Requirement: 应用外壳与导航

已进入系统的用户 SHALL 看到一个固定顶栏与主内容区；顶栏 MUST 提供品牌入口、当前身份切换与深色模式开关；宽屏 MUST 提供左侧主导航，窄屏 MUST 提供底部导航；当前页面 MUST 在导航中可辨认。宽屏主导航 MUST 按「浏览 / 我的」分组展示三个主页面，并 MUST 在导航底部提供当前用户资料入口，该入口展示头像、昵称与一行身份摘要；资料入口 MUST 以选中态标识当前页。

#### Scenario: 顶栏与主导航
- **Given** 用户已选择演示身份
- **When** 用户进入任一页面
- **Then** 顶栏展示 RouteMe 品牌标记与「路觅」字样
- **And** 顶栏提供身份切换与深色模式开关
- **And** 左侧导航按「浏览 / 我的」分组展示「旅行灵感 / 发布行程 / 我的旅行」，当前页对应项以背景与文字双重区分

#### Scenario: 导航跳转
- **Given** 用户在首页
- **When** 用户点击「发布行程」
- **Then** 路由切换到发布页且导航高亮随之变化
- **And** 点击品牌标记回到首页

#### Scenario: 资料入口
- **Given** 用户已进入系统
- **When** 用户查看宽屏主导航底部
- **Then** 看到由头像、昵称与身份摘要组成的资料入口
- **And** 摘要优先展示「学校 · 专业」，缺失时降级为职业，再缺失时显示「资料未完善」
- **And** 点击后进入 `#/profile/setup`
- **And** 停留在该页时资料入口以背景与文字双重区分标识当前页

#### Scenario: 窄屏导航
- **Given** 视口宽度 ≤ 900px
- **When** 用户浏览任一页面
- **Then** 左侧导航收起、底部标签栏出现
- **And** 三个导航项仍可到达对应页面
- **And** 页面无横向滚动

#### Scenario: 键盘可达
- **Given** 用户使用键盘
- **When** 用户在页面首部按 Tab
- **Then** 可跳过导航直达主内容区
- **And** 焦点元素有可见轮廓
