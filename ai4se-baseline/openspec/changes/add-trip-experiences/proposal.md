# 变更提案：add-trip-experiences

- **需求：** REQ-004（`requirement-workspace/requirements/REQ-004-trip-experiences.md`）
- **能力：** `trip-experiences`（ADDED）｜ **迭代：** 3「P0 稳定后完成」｜ **规模：** S（闭环收口，页面 1 个 + 展示位复用）

## 问题

REQ-002/003 完成了「灵感 → 发布 → 找同行 → 一起旅行」，但旅行结束后体验无法沉淀，闭环缺少收口。产品要验证第三个核心假设——**游后分享能够成为下一位用户的旅行灵感**。本提案新增 `trip-experiences` 能力：让完成旅行的用户对已结束且参加过的行程发布文字体验（感想、路线强度、一条建议），展示在原计划详情页与灵感首页，并让其他用户「参考此行程发布」快速创建新计划，把体验转化为下一轮灵感，形成完整闭环。

## 范围

**In scope（业务能力与页面）**

- 游后分享发布：仅对「已结束且自己参加过」的行程；填写文字感想；评价路线强度（轻松/适中/较累）；填写一条给后来者的建议。
- 图片上传：增强项；时间紧张时降级为纯文字 + 项目内置封面图（可裁剪）。
- 分享展示位：原计划详情页的游后分享区、灵感首页的「旅行体验」视图（复用 REQ-002 展示位）。
- 参考此行程发布：在已结束行程或分享详情提供按钮，点击后预填目的地、路线描述、兴趣标签；日期、人数、集合地点必须由新用户重新填写；后端接口可降级为前端预填。

**Out of scope**

- 行程浏览/筛选/发布/详情基础能力（→ REQ-002）；匹配/申请/聊天/我的旅行/安全（→ REQ-003）。
- 短视频、直播、复杂内容社区、个性化内容推荐算法（→ P2/不做）。

## 影响面（业务）

| 位置（能力 / 页面） | 改动 |
|---|---|
| `trip-experiences` 能力 | 新增：游后分享发布、参考此行程发布编排 |
| `trip-plans` 展示位（跨能力触点） | 详情页新增游后分享区、首页新增「旅行体验」视图、发布页承接「参考此行程」预填入口；不改变行程数据所有权，仅新增展示与预填编排 |
| `trip-companions`（消费方，不改动） | 依赖其「已结束 + 参加过」判定与我的旅行「可分享体验」入口 |
| 游后分享页 | 新增业务页面 |
