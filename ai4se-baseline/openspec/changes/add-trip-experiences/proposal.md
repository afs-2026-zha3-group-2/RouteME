# 变更提案：add-trip-experiences

- **需求：** REQ-004（`requirement-workspace/requirements/REQ-004-trip-experiences.md`）
- **能力：** `trip-experiences`（ADDED）｜ **迭代：** 3「P0 稳定后完成」｜ **规模：** M（新页面 1 个 + 两处展示位 + 发布页预填编排）
- **原型：** `docs/prototype/`（`prototype.html`、`stories.html` S15–S17、`store.js`、`data.js`）｜ **原型冲突裁决：** 以原型为准，例外见 §原型对齐决议

## 问题

REQ-002 与 REQ-003 完成了「灵感 → 发布 → 找同行 → 一起旅行」，但旅行结束后体验无法沉淀，闭环缺少收口。产品要验证第三个核心假设——**游后分享能够成为下一位用户的旅行灵感**。本提案新增 `trip-experiences` 能力：让完成旅行的用户对「已结束且自己参加过」的行程发布文字体验（真实感受、路线强度、一条建议），展示在原计划详情页与灵感首页的「旅行体验」视图，并让其他用户「参考此行程发布」快速创建新计划，把体验转化为下一轮灵感。

## 范围

**In scope（业务能力与页面）**

- 发布/修改游后体验：仅「已结束且自己参加过（发布者或已接受同行者）」的行程具备资格；内容为真实感受（≥10、≤400 字）、路线强度（轻松/适中/较累）、给后来者的一条建议（必填，≤120 字）；同一用户对同一行程只有一条体验，再次提交即修改。
- 纯文字 + 内置封面：不做图片上传，体验以文字与项目内置封面展示，不阻断分享。
- 展示位一：原计划详情页的「游后真实体验」区，展示作者、强度、感受与建议，并提供「修改我的体验 / 发表游后体验」入口。
- 展示位二：灵感首页「旅行体验」视图，与「旅行计划」视图切换；体验卡展示行程标题/目的地/作者/强度/感受摘要/建议，支持关键词、目的地与兴趣筛选，按发布时间倒序。
- 参考此行程发布：在已结束行程详情与体验卡上提供入口，进入发布页时预填目的地、途经点与兴趣标签；标题、日期、人数、集合区域与补充说明必须由新用户重新填写。
- 我的旅行入口：在「已完成」分组内标识是否已分享，并提供发表/修改入口。
- 分享边界：页面常驻提示不写入同行者电话、学校班级与住宿地址。

**Out of scope**

- 行程浏览/筛选/发布/详情基础能力（→ REQ-002）；匹配/申请/聊天/我的旅行/举报（→ REQ-003）。
- 图片/视频上传、富文本、评论/点赞/收藏、内容审核后台、个性化推荐算法（→ P2/不做）。
- 批量分享、跨行程聚合主页、分享排行榜、草稿箱。

## 影响面（业务）

| 位置（能力 / 页面） | 改动 |
|---|---|
| `trip-experiences` 能力 | 新增：体验发布/修改、双展示位查询、参考发布预填数据 |
| `trip-plans` 展示位（跨能力触点） | 详情页新增游后体验区；首页新增「旅行体验」视图；发布页承接 `?from=` 预填入口；不改变行程数据所有权与状态 |
| `trip-companions`（消费方，不改动） | 复用 `participants`（发布者 + 已接受同行者）判定「参加过」，复用「已完成」分组入口 |
| 游后分享页 / 首页体验视图 | 新增业务页面与视图 |
| 我的旅行（已完成） | 增加「发表/修改体验」入口与已分享标记 |

## 原型对齐决议

原型与需求文档不一致处，按下表收口（证据：`docs/prototype/store.js`、`ui.js` S15–S17、`data.js`）：

| 冲突点 | 需求文档 | 原型 | 本 change 裁决 |
|---|---|---|---|
| 内容长度 | 未量化 | 感受 ≥10、≤400；建议 ≤120 | 按原型 |
| 强度枚举 | 轻松/适中/较累 | `RELAXED/MODERATE/TIRING` + 文案 | 按原型，wire 值 `relaxed/moderate/tiring` |
| 每人每行程条数 | 未限制（deferred） | 同一用户只有一条，再次保存即修改 | 按原型（一条，可修改） |
| 分享资格 | 已结束 + 参加过 | 已结束 + `isParticipant`（发布者也计入） | 按原型：发布者与已接受同行者都可分享 |
| 体验图片 | 增强项，可降级 | 无上传，内置封面 | 按原型：纯文字 + 内置封面 |
| 首页体验视图 | 「旅行体验」切换 | 独立视图 + 关键词/目的地/兴趣筛选 + 最新排序 | 按原型 |
| 参考发布预填 | 目的地、路线描述、兴趣；日期/人数/集合地点重填 | 预填目的地、途经点、标签、**人数**；清空标题/日期 | **按需求**：人数也必须重填（原型复制人数视为待修） |
| 我的旅行入口 | 「可分享体验」入口 | 已完成卡片显示发表/修改 + 已分享标记 | 按原型 |
| 分享统计 | 未要求 | 个人资料弹窗展示分享数 | 不做（资料弹窗不在 MVP） |
