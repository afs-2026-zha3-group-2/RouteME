# trip-experiences 增量规格

## ADDED Requirements

### Requirement: 对已结束且参加过的行程发布游后体验

系统 SHALL 仅允许用户对「已结束且自己参加过」的行程发布游后体验，体验 MUST 包含文字感想、路线强度评价与一条给后来者的建议；不具备资格时 MUST 拒绝。

#### Scenario: 具备资格时发布体验
- **Given** 一条已结束且用户参加过的行程
- **When** 用户进入游后分享并填写文字感想、选择路线强度（轻松/适中/较累）、填写一条给后来者的建议后发布
- **Then** 系统保存该体验
- **And** 该体验可被其他用户查看

#### Scenario: 不具备资格时拒绝分享
- **Given** 一条尚未结束的行程，或用户并未参加过该行程
- **When** 用户尝试对其发布游后体验
- **Then** 系统拒绝并提示不具备分享资格

#### Scenario: 图片为增强项时不阻断纯文字分享
- **Given** 图片上传作为增强能力暂不可用（时间紧张降级）
- **When** 用户发布游后体验
- **Then** 系统仍允许发布纯文字体验并展示项目内置封面
- **And** 分享不因缺少图片而被阻断

### Requirement: 游后体验在原计划与灵感首页展示

系统 SHALL 把已发布的游后体验展示在原计划详情页与旅行灵感首页，使其成为其他用户可浏览的新旅行灵感。

#### Scenario: 在原计划详情页展示分享
- **Given** 一条已发布的游后体验
- **When** 用户查看该体验所属的原计划详情页
- **Then** 详情页的游后分享区展示该体验的文字感想、路线强度与建议

#### Scenario: 在灵感首页展示分享
- **Given** 一条已发布的游后体验
- **When** 用户在旅行灵感首页切换到「旅行体验」视图
- **Then** 首页展示该体验
- **And** 其他用户可从中获得新的旅行灵感

### Requirement: 参考此行程发布以产生新灵感

系统 SHALL 在已结束行程或其分享详情提供「参考此行程发布」入口，点击后 MUST 预填目的地、路线描述与兴趣标签，而日期、人数与集合地点 MUST 由新用户重新填写，从而把体验转化为一条新的旅行计划。

#### Scenario: 参考此行程发布并预填
- **Given** 一条已结束行程或其游后分享详情
- **When** 用户点击「参考此行程发布」
- **Then** 系统预填目的地、路线描述与兴趣标签到新建行程表单

#### Scenario: 日期人数与集合地点必须重填
- **Given** 用户由「参考此行程发布」进入新建行程表单
- **When** 用户准备提交
- **Then** 日期、人数与集合地点要求用户重新填写
- **And** 这些字段不沿用原行程的取值

#### Scenario: 参考发布后端不可用时降级为前端预填
- **Given** 参考发布的后端能力作为增强项暂不可用（降级）
- **When** 用户点击「参考此行程发布」
- **Then** 系统仍以前端预填方式带入目的地、路线描述与兴趣标签
- **And** 「分享体验 → 新灵感 → 发布新行程」的闭环不被阻断
