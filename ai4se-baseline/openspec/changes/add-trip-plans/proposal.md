# 变更提案：add-trip-plans

- **需求：** REQ-002（`requirement-workspace/requirements/REQ-002-trip-plans.md`）
- **能力：** `trip-plans`（ADDED）｜ **迭代：** 1「灵感与发布」｜ **规模：** M（闭环地基，页面 4 个）
- **原型：** `docs/prototype/`（`prototype.html`、`stories.html` S03–S05）｜ **原型冲突裁决：** 以原型为准，见 §原型对齐决议

## 问题

REQ-001 只验证了脚手架链路，RouteME 还没有任何业务能力。产品价值闭环「旅行灵感 → 发布行程 → 发现同行者 → …」缺少起点：用户既看不到别人的真实旅行计划，也无法发布自己的行程。本提案新增 `trip-plans` 能力，让大学生能选择演示身份进入系统、在灵感首页浏览并筛选公开行程、发布自己的旅行计划并查看行程详情，从而验证「用户愿意发布可被他人理解的旅行计划」这一核心假设，并为 REQ-003（同行匹配）与 REQ-004（游后分享）提供可筛选的行程池与状态锚点。

## 范围

**In scope（业务能力与页面）**

- 演示身份：3 个预设演示账户（林见夏 / 陈屿 / 苏念），选择后进入系统；演示过程中可切换身份，后续操作以新身份进行（不做注册 / 验证码 / 找回密码）。
- 旅行灵感首页：默认展示**未结束**（招募中 + 已满员）的公开行程卡片；卡片含标题、目的地、起止日期、途经点摘要、兴趣标签、发布者昵称、已加入 / 计划人数、状态文字。
- 筛选与排序：搜索（标题 / 目的地 / 途经点 / 标签 / 发布者昵称，大小写不敏感包含）、目的地（固定候选精确匹配）、日期区间（出发不早于 / 不晚于，与行程日期有交集）、兴趣标签多选（命中任一）、排序（按出发日期 / 按最新发布）；已应用条件可见、可一键清除；无结果展示空状态并保留条件；加载中展示骨架。
- 发布行程：必填（标题、目的地、出发日期、结束日期、至少两个途经点、计划人数）；选填（集合区域、预算范围、兴趣标签、补充说明）。约束：标题 ≤ 40 字；目的地来自固定候选；结束日期不早于出发日期；途经点 ≥ 2；计划人数 2–12（含发布者）；预算下限 ≤ 上限；兴趣标签最多 5 个。
- 行程详情：完整途经点、日期与人数、发布者简介与旅行兴趣、当前同行者、状态徽标；同行申请入口按资格显示（提交行为属 REQ-003）；游后分享区占位（内容属 REQ-004）。
- 行程状态：招募中 / 已满员 / 已结束；状态用文字表达，不只靠颜色。已满员由已加入人数达到计划人数产生；发布者可把自己的行程**标记为已结束**（演示旅行完成）。

**Out of scope**

- 同行申请提交 / 接受 / 拒绝 / 取消、人数接受联动、聊天、退出 / 举报 / 安全提示（→ REQ-003）。
- 游后分享内容、「旅行体验」视图、参考此行程发布（→ REQ-004）。
- 按匹配度排序与匹配原因（→ REQ-003 的匹配能力；本 change 只提供排序位，不实现打分）。
- 原型里的演示增强但未进本迭代范围的：编辑行程、删除行程、取消行程、保存常用筛选、拖拽改序、批量处理、撤销、无限信息流 / 分页、AI 推荐、地图导航、实时定位、订票 / 酒店 / 支付、实名认证、积分勋章、头像上传（→ P2 / 明确不做 / 后续 change）。
- 已取消（`CANCELLED`）状态：原型用作删除 / 取消演示，MVP 不提供取消入口，本 change 不实现该状态。

## 影响面（业务）

| 位置（能力 / 页面） | 改动 |
|---|---|
| `trip-plans` 能力 | 新增：身份进入 / 切换、浏览、搜索筛选排序、发布、详情、状态与标记已结束 |
| 旅行灵感首页 | 首页语义由「问候语展示」演进为「灵感首页」；`hello-world` 脚手架验收能力保留不动 |
| 演示身份门 / 发布行程页 / 行程详情页 | 新增业务页面 |
| 下游 `trip-companions` / `trip-experiences` | 消费本能力的行程、状态、筛选与兴趣标签（不在本 change 实现） |
| 跨能力触点 | 状态定义锚点在本能力；REQ-003 触发「已满员」、结束行程时处理待处理申请；REQ-004 消费「已结束」判定分享资格 |

## 原型对齐决议

原型与初版 proposal 不一致处，按下表以原型为准收口（证据：`docs/prototype/store.js`、`stories.html` S03–S05）：

| 冲突点 | 初版 proposal | 原型 | 本 change 裁决 |
|---|---|---|---|
| 首页筛选 | 目的地 + 日期 | 搜索、目的地、日期区间、兴趣多选、排序 | 按原型，全部纳入 |
| 日期筛选 | 「某个日期」 | 出发不早于 / 不晚于（区间与行程有交集） | 按原型 |
| 卡片状态视图 | 公开行程 | 默认只列未结束行程（招募中 + 已满员） | 按原型 |
| 发布约束 | 未写具体上限 | 标题 ≤ 40、途经点 ≥ 2、人数 2–12、预算下限 ≤ 上限、标签 ≤ 5 | 按原型 |
| 已结束触发 | 未定义 | 发布者「标记为已结束」 | 按原型 |
| 申请入口 | 详情页占位入口 | 仅招募中且未满员且非本人时可用 | 按原型（提交仍属 REQ-003） |
| 是否 `CANCELLED` | 未提 | 原型有取消 / 删除演示 | 不纳入 MVP，删除 / 取消属后续 change |
| 匹配度排序 | 未提 | 首页有「按匹配度」 | 排序位保留，打分归 REQ-003 |
| 状态数量 | 3 态 | 4 态（含已取消） | 3 态；已取消不入 MVP |
