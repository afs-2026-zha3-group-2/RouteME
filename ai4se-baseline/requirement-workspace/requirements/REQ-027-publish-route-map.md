## 1. Intent

一句话：发布行程时在地图上加点、拖顺序、切出行方式，提交前就能看到自己要走的路线；提交出去的仍然只是一串地名和出行方式。

## 2. Actors

| 角色 | 权限边界 |
|---|---|
| 发布者（发布页） | 加 / 删 / 排序途经点，切换出行方式，生成与重算路线；占位名被拦截时改名。 |
| 浏览者 / 同行者（详情页） | 只读；按发布顺序看到途经点与路线。 |
| 系统 | 规划路线、渲染折线与编号、口径校验（2–8 点、占位名）、降级到直线。 |
| 高德路线服务 | 真实路线、距离与时长；不可用时由系统降级，不阻断发布。 |

## 3. In / Out scope

**In scope**

- 发布页第 2 段标题与提示：`sectionRoute` → 「路线规划」。
- 地图路线编辑器：地图 + 搜索候选 + 地图点选 + 景点标记。
- 途经点面板：`已选途经点 n/8`、排序（拖拽 / 上下按钮）、删除、清空、生成按钮。
- 路线渲染：折线、起点 / 终点、编号 pin、总距离、总时长、逐段说明。
- 出行方式：三档就地切换；公共交通带目的地城市；首次生成后自动重算。
- 降级：直线虚线 + 面向用户的「示意 / 估算」提示。
- 提交：`stops: string[]`（当前顺序、去空、2–8 个）+ `travel_mode`；占位名拦截。
- 导航：移除「旅行地图」一级入口；页面与深链保留。
- 测试：重写 `trips.spec.ts` 失效断言；新增模式列表、占位名、降级文案覆盖。

**Out of scope**

- 坐标、`place_id`、polyline 入库；契约版本与迁移变更。
- 路线持久化 / 收藏 / 分享 / 路线重合度打分。
- 详情页 `AmapTripMap` 的「按名称重算路线」口径。
- 同行者匹配面板进发布页。
- AI 规划页、AI 快照结构。
- 探索页既有缺陷（公共交通未传城市、`RouteLayer` 重投影、导航条漂移）。

## 4. Scenarios + AC hints（SHALL 式，可观察）

> 基线 7 场景（填写完整必填项后成功发布 / 选填项可留空 / 必填项缺失 / 日期不合法 / 途经点不足两个 / 计划人数越界 / 预算区间倒置）在 Delta 中原文保留，编号不变。

### A. 路线录入与渲染

1. **S28-1 在地图上添加途经点并看到路线** — Given 已选目的地城市，When 通过搜索 / 地图点选 / 景点标记加入 2 个及以上地点并点击「生成旅行路线」，Then 按加入顺序绘制路线并展示起点、终点、编号、总距离与总时长；同一地点重复加入不产生重复途经点。
2. **S28-2 途经点顺序可调整** — Given 已有 3 个及以上途经点，When 拖拽或使用上下按钮，Then 折线与编号立即按新顺序重排；提交后详情页按同一顺序展示。
3. **S28-3 途经点超过上限时被拦截** — Given 已有 8 个途经点，When 加入第 9 个，Then 拒绝新增并提示最多 8 个；已有途经点与路线不变。

### B. 出行方式与规划

4. **S28-4 切换出行方式重算路线** — Given 已生成过路线，When 在三档之间切换，Then 自动重算并更新距离与时长，无需再次点击生成；选项为「自驾 / 骑行 / 公共交通」，不出现「步行」也不出现「驾车」；行程顺序面板标题同步。
5. **S28-5 公共交通使用目的地城市规划** — Given 选择「公共交通」，When 规划，Then 请求以目的地城市限定换乘范围；失败时按降级口径提示，不展示错误换乘结果。

### C. 降级

6. **S28-6 路线服务不可用时按顺序直线示意** — Given 已有 2 个及以上途经点，When 服务不可用或超时，Then 按顺序画直线并标注「示意 / 估算」，页面其余部分可用、地图不空白。
7. **S28-7 降级提示不暴露实现细节** — Given 进入直线示意状态，Then 提示只说明「示意 / 估算」及下一步，不出现后端服务名、端口、代理或重载。

### D. 提交与数据边界

8. **S28-8 发布只提交地名与出行方式** — Given 已排好顺序，When 提交，Then 请求体只含按顺序排列的名称数组与出行方式，不含坐标或新字段，契约版本不变。
9. **S28-9 坐标占位名不得进入发布** — Given 途经点名称仍是「地图选点 {经度}, {纬度}」，When 提交，Then 拒绝并提示改名，不产生行程；改名后可正常发布。

### E. 预填与展示

10. **S28-10 AI 预填路线进入编辑器后可编辑** — Given 从 AI 推荐或参考行程进入，When 预填，Then 预填点出现在同一编辑器并可规划；可继续排序、删除、重算后发布。
11. **S28-11 窄屏与双主题不溢出** — Given 1440 / 1024 / 768 / 390 与浅 / 深色，When 渲染地图与列表，Then 正常堆叠或换行、无横向溢出，文字可读。
