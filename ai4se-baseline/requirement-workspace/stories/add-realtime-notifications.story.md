# Story file — REQ-023 / add-realtime-notifications

- **Parent REQ：** REQ-023（`requirements/REQ-023-realtime-notifications.md`）
- **Change：** `add-realtime-notifications`（`notifications` ADDED）
- **拆解模式：** Workflow（记录 → 推送 → 计数 → 指示与跳转）
- **范围说明：** 本文只覆盖本 change；通知历史、偏好设置、邮件 / OS 推送，以及申请与聊天规则的改动均在范围外。

## S23-1 — 申请到达时告知发布者

- **用户声音：** 作为行程发布者，有人申请我的行程时我希望立刻知道，不管我当时在应用哪个页面，而不是等我下次打开申请处理页才发现。
- **AC 摘要：**
  - 申请成功时，为发布者创建恰好 1 条 `application_received`，带申请者、行程与申请文案。
  - 被既有规则拒绝的请求（重复、满员、已关闭）不产生任何通知。
  - 通知在 3 秒内到达发布者已打开的会话，无需刷新。
  - 点击它打开该行程页。
- **Size：** M
- **Spec：** `specs/notifications/spec.md`「申请类通知」
- **场景：** REQ-023 §4 S23-1、S23-4、S23-10、S23-23

## S23-2 — 裁决后告知申请者

- **用户声音：** 作为申请者，我希望申请被接受或被拒绝时立刻知道，而不是反复去「我的旅行」里翻。
- **AC 摘要：**
  - 接受为申请者创建 1 条 `application_accepted`；拒绝创建 1 条 `application_rejected`。
  - 通知与裁决同事务创建，但通知失败不回滚裁决。
  - 通知 3 秒内到达申请者，并在刷新后仍然存在。
  - 点击它打开该行程页。
- **Size：** S
- **Spec：** `specs/notifications/spec.md`「申请类通知」
- **场景：** REQ-023 §4 S23-2、S23-3、S23-7、S23-23、S23-26

## S23-3 — 统计未读并让计数诚实

- **用户声音：** 我想要一个数字告诉我还有多少事要处理，并且在我真正读过之后它就会减少。
- **AC 摘要：**
  - 列表响应返回最新 50 条与拆分的未读计数（总数 / 申请类 / 消息类）。
  - 计数由持久化的未读行派生，刷新或重连后仍是同一个数。
  - 读单条、读一个会话、读全部，各自恰好减一，且只影响本人。
  - 两个用户之间互不影响计数。
- **Size：** M
- **Spec：** `specs/notifications/spec.md`「未读计数与列表」「标读」
- **场景：** REQ-023 §4 S23-7 ~ S23-9、S23-16 ~ S23-20

## S23-5 — 收到新消息时告知接收方

- **用户声音：** 有人给我发消息时，我希望在会话列表和聊天入口上立刻看到未读提示，而不是靠我自己反复点开每个会话去猜。
- **AC 摘要：**
  - 消息发送成功时，为接收方创建恰好 1 条 `message`，带该会话（`trip_id` + 发送方）与消息 id。
  - 自己给自己发消息不创建通知。
  - 通知在 3 秒内到达接收方；点击它打开该会话。
  - 会话未打开时给提示条；会话已打开时直接追加、不提示（D10、D14）。
- **Size：** S
- **Spec：** `specs/notifications/spec.md`「消息通知」
- **场景：** REQ-023 §4 S23-5、S23-6、S23-10、S23-23、S23-24

## S23-4 — 在界面上显示计数并能一键到位

- **用户声音：** 我希望铃铛与聊天入口上有一个带数字的点，一次点击就能到那个行程或那个会话。
- **AC 摘要：**
  - 顶栏铃铛显示未读总数，点开是面板：最新条目带动作人、文案、时间、未读标记，并有「全部已读」。
  - 侧栏聊天入口与移动 tab 显示消息数；会话列表显示分会话未读数。
  - 为 0 时不显示徽标；徽标是数字，不能只有颜色。
  - 对当前不可见的事件给提示条；当前打开会话的消息直接出现而不提示。
  - 打开会话只清该会话的消息类通知。
- **Size：** M
- **Spec：** `specs/notifications/spec.md`「壳层指示器」「实时投递」
- **场景：** REQ-023 §4 S23-11 ~ S23-15、S23-21 ~ S23-23、S23-25、S23-26
